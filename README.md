# Izvešanas pieteikumi

Ietvara lapa, kas atver Apps Script lietotni "Izvešanas pieteikumi" pa visu telefona ekrānu
(bez baltām joslām augšā un apakšā) un ļauj to pievienot sākuma ekrānam kā lietotni.

Dati un loģika atrodas Google Apps Script / Google Sheets — šī lapa tikai ielādē lietotni.
